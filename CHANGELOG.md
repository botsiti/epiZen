# Changelog

Each delivered version has a matching [GitHub Release](https://github.com/botsiti/epiZen/releases)
with its app archive and validation notes.

## 0.11.0 — 2026-11-10

Reliable Retina prompt placement and close/reopen recovery, separate Text/Speak controls,
model and effort pickers, audio metering and optional glass surfaces.
[Full release notes](releases/0.11.0.md).

## 0.10.0 — 2026-11-10

Native transcription model selection, safer quick text handoffs, and the pending XP/quest-rule
foundations with Unicode category tags. [Full release notes](releases/0.10.0.md).

## 0.9.0 — 2026-11-09

Configurable Spike plugin, global quick text and dictation prompts, independent voice providers
including OpenRouter, and ⌘8 for the conversation sidebar. Faster link indexing and quieter
animation work, with microphone, dragging and cross-window recovery fixes. Advanced library
filters and cover pagination are restored. [Full release notes](releases/0.9.0.md).

## 0.8.0 — 2026-11-09

Spike personal assistant and desktop companion, editable Obsidian Bases, optional per-vault
plugins and display preferences, with reviewed note actions and isolated recovery.
[Full release notes](releases/0.8.0.md).

## 0.7.0 — 2026-11-03

Focused settings pages, daily-note connection previews, selectable library catalogues, and
safer, clearer note and folder creation. [Full release notes](releases/0.7.0.md).

## 0.6.1 — 2026-11-03

Reliable desktop display setup and lint isolation for nested worktrees.
[Full release notes](releases/0.6.1.md).

## 0.6.0 — 2026-11-03

Workspace shortcuts, sidebar toggles and a searchable keyboard reference, plus sleep entry in
hours and minutes with failed-save recovery. [Full release notes](releases/0.6.0.md).

## 0.5.0 — 2026-11-02

Persistent habits with archive/reactivation and history, plus consistent status colours for
check-ins and averages. [Full release notes](releases/0.5.0.md).

## 0.4.0 — 2026-11-02

An interactive Wheel of Life, a dedicated Decisions journal, monthly spending in Home summaries,
and quest editing and deletion. [Full release notes](releases/0.4.0.md).

## 0.3.0 — 2026-11-01

Monthly reflections, money and life-area reviews, a year of summaries, clearer quest XP,
safer vault setup, and more consistent motion. [Full release notes](releases/0.3.0.md).

## 0.2.0 — 2026-10-30

New brain identity and media-type badges, safe file actions with automatic backlink updates,
compact Home collections, dedicated Quests and Statistics, and the current library and periodic
note improvements. [Full release notes](releases/0.2.0.md).
