# Epizen 0.7.0

Settings now has focused pages instead of one long form, with a searchable navigation list,
compact grouped controls and a dedicated Hotkeys reference.

- Daily, weekly and monthly notes each have their own location and date-format settings.
  Connect existing daily notes by choosing a vault folder and reviewing the detected dates.
  Date-order examples explain numeric filenames; duplicate-date choices and unusual names
  have their own review area. Connecting notes never moves or rewrites them.
- Homepage settings brings together your birth date, podcast artwork and the catalogues used
  when adding media. Choose Wikipedia or MusicBrainz for albums, Wikipedia or Open Library
  (or both) for books, and Wikipedia or iTunes for podcasts. Films use Wikipedia. Every source
  uses the same result cards, editing form and library pages.
- The file explorer has separate New note, New folder and Collapse buttons. Creation shows
  the destination before saving and retains your draft if a name is already taken. Empty
  folders remain visible after reopening the app.
- Files & folders settings stores defaults per vault: the current note's folder, the vault
  root or a specified folder. Periodic notes keep their own locations.

Wikipedia podcast results describe shows; enter the episode title yourself after choosing a
show. iTunes also provides episode listings. Catalogue preferences apply to Add; the existing
cover-recovery searches keep their established matching and fallback behavior.

The feature passed the fast gate (733 frontend tests and 67 Rust tests) and five focused native
journeys covering settings persistence, chosen catalogue results, existing-note recognition,
folder creation and collision recovery. Screenshots were reviewed on the built-in Retina display
at regular and narrow widths. The release PR records the full regression and production smoke
results before shipping.

No note-format migration is needed. Existing Markdown is unchanged by settings or note connection.
Roll back by reinstalling 0.6.1; keep any notes or folders you created in 0.7.0.

For macOS on Apple Silicon, ad-hoc signed and not Apple Developer ID notarized. Production builds
exclude test-only WebDriver components.
