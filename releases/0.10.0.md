# Epizen 0.10.0

Choose Spike's transcription model from a native dropdown and use its quick text prompt from any app.

## Changes

- Dictation settings offer provider-specific model choices, including MAI-Transcribe 2 on OpenRouter,
  plus a Custom model option. Existing custom identifiers are preserved.
- The quick prompt keeps its text locked until the conversation acknowledges the handoff. Failed
  submissions retain the text for retry. Use **⇧⌘Space** to type, **Enter** to send, **Shift+Enter**
  for another line, and **Escape** to save and close. **⌥⇧⌘Space** starts or finishes dictation.
- Include the pending XP foundations: exact arithmetic, versioned per-vault reward rules stored
  outside notes, modern quest reward parsing and conditional edits, and Unicode daily-category tags.
  The configurable XP settings screen is not part of this release. Existing unversioned quests keep
  their previous scoring rules; notes are not automatically migrated.

## Compatibility and validation

Notes remain ordinary Markdown. API credentials remain in macOS Keychain. Remote transcription
requires access to the selected model; paid-provider and physical microphone checks are not automated.

Release validation includes the required fast gate, the full desktop workflow with screenshot review,
and an isolated production smoke check. Results are recorded in the release pull request before merge.
Tests use vault copies and fake providers, never personal notes or calendars.

For macOS on Apple Silicon. The app is ad-hoc signed and **not Apple Developer ID notarized**.
Install the previous GitHub Release to roll back the app; never overwrite notes during rollback.
