# Epizen 0.19.0

- Double-click a timed Calendar block to edit it. A linked task shows its description, category,
  logged minutes, and source note. A writable Apple Calendar event can be edited directly,
  including its title and multiline description.
- Calendar blocks use the latest linked task text. Moving a block displays its new scheduled
  date and keeps edits connected to the task in its original Markdown note.
- The default 07:00–22:00 week uses the available window height. Smaller windows and expanded
  night hours can scroll to keep the grid readable.

Existing Markdown notes need no migration. The release is for Apple Silicon and uses ad-hoc
signing. Apple Developer ID notarization is unavailable for this build.

The fast checks and frontend build passed. Headless layout checks covered 1280 × 780,
1440 × 900, and 1920 × 1040. Native desktop E2E and visual review remain deferred.
