# Epizen 0.9.0

Spike becomes an optional, configurable plugin with a quick prompt for use above other apps,
independent dictation providers, and keyboard access. This release also reduces avoidable indexing
and animation work and restores advanced library filters and cover pagination.

## What’s new

- Enable Spike per vault in **Settings → Plugins**, then Configure its connection, desktop companion,
  profile, action review and voice preferences. Existing connected assistants/companions stay enabled.
- Click desktop Spike or Talk for a compact prompt. **⇧⌘Space** opens/closes typing and
  **⌥⇧⌘Space** starts/finishes dictation. **⌘8** toggles the full conversation sidebar.
- Dictation can use on-device recognition, OpenAI or OpenRouter with a selected transcription model
  and Keychain credential, independently of the assistant’s Codex/OpenAI conversation connection.
- Quick drafts survive hiding and restarting. Handoffs retain a stable identity until the conversation
  saves the request, preserve separate sidebar drafts, and keep note/calendar changes in normal review.
- Advanced library filters and cover pagination are restored. The GitHub feature guide lists every
  shipped built-in plugin and workflow: [all features](https://github.com/botsiti/epiZen/blob/v0.9.0/docs/FEATURES.md).

## Performance and fixes

- Reuse normalized filename and folder-suffix indexes, including epiBase. A 5,000-file / 10,000-lookup
  fixture produced identical results in about 7 ms versus 14.3 seconds for repeated full-file scans.
  This measures the lookup bottleneck, not overall application speed.
- Animate Spike only at original atlas frame boundaries, stop work while hidden/paused, and keep the
  tab-bar mark still. Typing no longer reparses earlier conversation Markdown.
- Fix stale microphone events stopping a newer recording, drag movement backlogs/overlapping gesture
  deadlocks, and save-control messages leaking between windows.
- Restrict companion windows to scoped capture/control commands. Keep preview utility windows on
  the main preview’s desktop and preserve failed drafts and conditional writes.

## Compatibility and privacy

Your notes stay ordinary Obsidian-compatible Markdown. Disabling Spike keeps its preferences and
conversation history and leaves notes untouched. API keys live in macOS Keychain. Remote dictation
sends recordings only to the selected provider when sent; API usage is billed by that provider.
Local speech requires permission and a supported installed language. Closing the main window while
Spike is enabled saves/hides it; **Quit Epizen** exits the app.

## Validation

The [required fast check for the application/test revision](https://github.com/botsiti/epiZen/actions/runs/42690139663)
passed 897 frontend tests, 91 Rust unit tests and 7 Rust integration tests, plus Clippy, ESLint,
both TypeScript projects, version consistency and fixture integrity. The
[full desktop results and screenshots](https://github.com/botsiti/epiZen/actions/runs/42690126656)
cover application/test revision [`e02e893`](https://github.com/botsiti/epiZen/commit/e02e8936031a158f4d75f677521ae0aa74c0cc62).
Subsequent release-note changes are documentation only; the latest PR revision must also pass its
required check before merge. Publishing waits for the full desktop run and screenshot review.

The normal production app built and passed an isolated local smoke check on the built-in display’s
Desktop 2. Focused native checks used a vault copy and fake audio/providers to verify plugin lifecycle,
draft recovery, review-before-write, companion opening, dictation, close/flush, shortcut registration/
release and window boundaries. The original demo fixture remained unchanged.

Physical global key presses and real microphone input were not exercised by automated local checks.
Paid-provider access depends on the selected account and model. No personal notes or calendars are
used by the test suite.

## Download and rollback

For macOS on Apple Silicon. The app is ad-hoc signed and **not Apple Developer ID notarized**.
Download the ZIP and verify it against `SHA256SUMS`.

Install a previous GitHub Release or revert the release PR and build a new patch version to roll back.
Never replace user notes when rolling back the app.
