# Epizen 0.20.0

Double-click a linked task in Calendar, select **Completed**, and choose **Save**. A check appears on its scheduled blocks and the daily note's plan percentage updates. Clear the checkbox and save to reopen the task.

The task stays in its original note, including when the block has moved to a different day. Completing it preserves its logged minutes and scheduled event. Existing notes and links need no migration.

Adding an album in Library now includes its Wikipedia tracks when the album and artist match. You can still choose the page and edition yourself. Existing imported track titles containing Wikipedia’s fraction styling display as ordinary text, including “8 1⁄2 Minutes” on *Emergency & I*.

Use **Choose cover…** when adding an album, movie, book or podcast episode to use a local PNG, JPEG, GIF or WebP image up to 10 MB. To supply an album's tracks yourself, paste one title per line in **Track list**. Epizen keeps the order, including repeated titles, and skips Wikipedia for that list.

For Apple Silicon Macs. The app is ad-hoc signed. Developer ID notarization is unavailable.

All seven fast checks passed. Tests covered canceling, conflicting writes, reopening, and file integrity on a copy of the demo vault. The production frontend also completed and reopened a moved task in offscreen WebKit with a simulated calendar. Offscreen WebKit also imported the standard 12 tracks from the Wikipedia response for *Emergency & I*. Native desktop journeys on GitHub verified custom artwork, manual track order and linked task completion. Local native windows were deferred because Desktop 2 was unavailable on the built-in display.
