# Epizen 0.8.0

Spike brings a personal assistant to the workspace, alongside editable Obsidian Bases and per-vault plugins.

## What changed

- Talk to Spike beside your notes or through the optional animated desktop companion. Conversations and unfinished drafts survive restarts.
- Connect using an existing ChatGPT subscription through installed Codex CLI, or an OpenAI API key kept in macOS Keychain. These are separate connections; Spike never silently switches billing.
- Review proposed library entries, ordinary notes, captured links, remembered preferences, thought records and calendar events before saving. Conflicts retain the draft and protect existing notes.
- Voice recording, on-device transcription for the subscription connection, and optional read-aloud have cancellation and recovery controls.
- Enable only the workflows a vault needs. Each plugin has display preferences; disabled features preserve the Markdown and their settings.
- Open and edit Obsidian `.base` files and embedded views, including tables, cards, lists, filters, formulas, properties and imports. Existing YAML and unrelated note text are preserved.
- Refreshed app branding and clearer boundaries between features, with independent recovery for optional screens.
- Local agent tests and previews stay on Desktop 2; native tests refuse to open windows unless that desktop is verified.

## Compatibility

Notes remain ordinary Obsidian-compatible Markdown and Bases remain YAML. No database migration or app-managed account is introduced. Settings and conversation history live outside the vault. Existing configured vaults retain their enabled workflows.

## Validation

Release validation is in progress. The latest local fast gate passed 863 frontend tests, 84 Rust unit tests and 7 native integration tests. All 14 assistant desktop journeys passed. The full local run exposed graph, preferences and layout failures; the release must complete clean remote validation before publication.

Real microphone input has not been verified on hardware. On-device transcription depends on macOS language support and permissions. Live subscription chat, reviewed note/library creation, profile recall and system read-aloud have been checked with disposable demo data.

## Download

For macOS on Apple Silicon. The app is ad-hoc signed and is not Apple Developer ID notarized.

## Rollback

Install a previous GitHub Release or revert the release PR and rebuild. Never replace user notes when rolling back the app.
