# Epizen 0.18.0

- The macOS menu-bar timer shows the current task’s category beside the time during a focus session.
- Create folders directly in the sidebar. Drag a note to a folder or use **Move to folder** from its context menu. Open tabs follow the note, and moves refuse name collisions.
- **Settings → Files & links** controls default folders, monthly photo storage, link syntax and paths, and automatic link updates when notes move or are renamed.
- Use **Control–Shift–O** to close other unpinned tabs, **Command–E** to switch between reading and editing, and **Command–S** to save. Hotkeys in Settings lists the new Markdown formatting shortcuts.

Notes remain ordinary Markdown. Moving a note preserves its calendar date and outgoing relative links. Pinned tabs and unsaved recovery drafts survive closing other tabs.

The published build is for Apple Silicon and uses ad-hoc signing. Apple Developer ID notarization is unavailable for this build. The release workflow runs the fast gate and verifies the app package. The full desktop suite and visual review are deferred to the evening run.
