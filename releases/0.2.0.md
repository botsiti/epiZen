Epizen 0.2.0 brings a new identity, clearer mixed library shelves, and file management that keeps
connected notes connected. This is the first packaged GitHub release of the current app.

## New and improved

- **New aqua glass brain logo** across the macOS app, sidebar and repository.
- **Media-type badges** on Home and the Library's All view: music note, camera, book, microphone
  and video symbol, styled to match the rating pills.
- **Rename with automatic backlinks.** Change a filename from its title or sidebar menu; incoming
  wikilinks, embeds and Markdown links follow it while labels, headings and block references stay intact.
- **File actions:** Duplicate, Reveal in Finder, Rename and recoverable Delete from the sidebar.
- **A quieter Home:** ten recent library entries and eight quests at a time, with links to the full views.
- **Dedicated Quests and Statistics:** month navigation, quest progress and XP, daily focus details,
  category breakdowns, and proportional habit completion bars.
- **Library refinements:** metadata and genre editing, album track favorites, podcast artwork
  preferences, and more resilient cover discovery.
- **Built-in periodic notes and Markdown highlights**, with optional habits and thought-record features.

## Included foundations

Plain Markdown vaults, tabs and navigation history, backlinks and graphs, daily/weekly/monthly
pages, local Apple Calendar planning, a focus timer and menu-bar panel, and guarded note writes
that preserve unsaved text when a conflict occurs. No accounts or app-managed sync.

## Download

`Epizen_0.2.0_macOS_arm64.zip` contains the production app for **macOS on Apple Silicon**. Unzip it
and move `Epizen.app` to Applications. `SHA256SUMS` contains the archive checksum. This build is
**ad-hoc signed and not Apple Developer ID notarized**; it contains no test-only WebDriver components.

## Validation

The release workflow verifies matching versions and the integrated commit, then runs the fast
checks before building the archive. Local desktop validation is recorded with the release PR.
