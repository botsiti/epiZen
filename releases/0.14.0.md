# Epizen 0.14.0

Settings now brings together 14 built-in plugins. Choose the tools you want for each vault, search their settings, and configure them individually.

- **Habits.** Add a routine in Settings → Habits, continue one found in older daily notes, or choose when to archive or reactivate it. Turning Habits off preserves its Markdown definitions and history.
- **Quests and daily tasks.** Edit the life spheres shown on Home, manage task categories under Periodic notes, and choose how each category divides XP across spheres. Task categories supply their own Markdown tags. Focus sessions and manually logged minutes use the same reward rules.
- **Calendar.** Choose a calendar time zone independently of the Mac. Timed Apple Calendar events follow that zone in the day and week views.
- **Menu bar.** Open today’s note or Calendar from the compact clock panel. Play locally generated white or brown noise and adjust its volume. Menu bar and Focus timer can run independently. Existing vaults inherit the menu-bar visibility they had before the upgrade.
- **Spike and appearance.** Use the companion’s inline text and voice controls, and manage the companion from Settings. Liquid Glass can display imported animated backgrounds, including GIF and MP4 files.

Plugin switches preserve saved preferences. Disabling Calendar stops linked task edits from updating Apple Calendar. Habit and daily-note writes check which vault is open before saving.

The integration passed 994 frontend and 121 Rust tests. The production app was smoke-tested with isolated vault copies on Apple Silicon. The release pull request records the release candidate’s desktop results.

For macOS on Apple Silicon. The app uses an ad-hoc signature and ships without Apple Developer ID notarization. To roll back, reinstall Epizen 0.13.0 and retain your vault and settings.
