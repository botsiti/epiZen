# Epizen 0.6.1

A maintenance release improving the reliability of desktop validation. App behavior and the Markdown note format are unchanged.

- Desktop tests now fail setup when the requested display is unavailable, rather than continuing after a logged error.
- Lint excludes nested worktrees, preventing duplicate checkout scans from exhausting memory.
- Two regression tests cover unavailable displays and positioning before showing a window.

The full local validation passed with these fixes: 65 Rust tests, 721 frontend tests and 63 desktop journeys. All 132 screenshots were reviewed in the overnight validation, and the demo vault remained unchanged. The production frontend build passed. The release PR records fresh fast-gate results.

No migration is needed. Roll back by reinstalling 0.6.0; notes are not rewritten.

For macOS on Apple Silicon, ad-hoc signed and not Apple Developer ID notarized. Production builds exclude test-only WebDriver components.
