# Epizen 0.17.0

- Choose from 41 illustrated habit icons. Search by name or activity, such as “walk steps,” “sleep,” or “budget.”
- Delete an active habit after confirming its name. Epizen removes its check-ins and earned XP and moves its definition to the vault trash. Archive keeps the check-ins and history.
- Home shows XP to the next level alongside the current level. Library, Calendar, Settings, and other screens use shorter labels and quieter surfaces.

Habit definitions and check-ins remain Markdown. If a check-in shares a line with a comment, move the comment to its own line before deleting the habit. Epizen checks the affected note revisions before writing and restores earlier edits if a later write fails, provided those notes still hold Epizen’s changes.

The production web build, Rust and TypeScript checks, and 1,019 Vitest tests passed locally. Vault-copy tests confirmed the exact deletion and rollback behavior. Headless previews covered Home, icon search, and the delete confirmation. The release workflow builds the production application for Apple Silicon. This bundle is ad-hoc signed and has no Apple Developer ID notarization.
