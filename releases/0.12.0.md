# Epizen 0.12.0

Spike now helps through Epizen’s screens and native actions:

- The quick prompt sits directly below Spike and follows dragging. Right-click hides both;
  ⇧⌘Space shows or hides them while retaining the draft.
- “Start CBT” opens today’s thought-record form, including from quick capture with the main
  window hidden. Repeated requests preserve an unfinished form.
- Add categorized daily tasks, weekly/monthly quests and supplied periodic reflections.
  Planned time is never recorded as completed work.
- Schedule an exact interval or find a full-duration free slot in the morning, afternoon or
  evening. Availability is checked again before saving, and the calendar opens at the result.
- Capture a selected Library title with its catalogue cover, date, rating and your comments.
  Failed downloads remain recoverable; retries reuse a saved attachment. The media page opens
  after saving.
- The built-in SPIKE.MD explains the available workflows. The vault’s root AGENTS.md and
  SPIKE.MD are reread as bounded preferences for each request, alongside the selected profile.

Notes remain ordinary Obsidian-compatible Markdown. Existing files are never replaced during
creation, and note saves still check their expected contents. Disabled plugins reject their
specialized assistant actions. Existing review/automatic preferences remain in effect. No
separate MCP server, database, or new account is required.

The local fast gate passed: 108 Rust unit tests, 8 native I/O integration tests and 956 Vitest tests, plus Clippy, ESLint, TypeScript, version and fixture checks. Native journey tests use temporary
vault copies, catalogue fixtures, fake AI providers and in-memory calendars. Physical system
shortcut presses and paid/live AI requests were not exercised; shortcut registration and routing
are covered independently. Full desktop regression and production package verification are required before delivery; their results are recorded in the release pull request.

For macOS on Apple Silicon. Ad-hoc signed, not Apple Developer ID notarized. Roll back by installing
a previous GitHub Release or reverting this release and rebuilding. Never overwrite notes when
rolling back the app.
