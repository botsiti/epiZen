# Epizen 0.16.0

## Habits

- See your routines in rounded rows with nine illustrated enamel icons. Select a day from the week strip or month calendar to log or undo a missed check-in.
- Point to a habit on a daily note or focus it with the keyboard to see its current and record streaks for that date.
- Use **Settings → Habits → XP settings** to set base XP, assign a life area, and preview or edit the rewards at each streak threshold. The higher rate takes effect on the check-in that reaches it. Earned XP contributes to daily totals and to life-area progress on Home.

Existing check-ins remain ordinary Markdown. Habits earn XP after you save their reward settings. Changes to rules or historical check-ins recalculate affected XP from the journal.

The change was verified with the Rust and TypeScript test suites, a production web build, and headless visual checks of the Habits view, XP settings, and daily streak tooltip. A desktop journey covers backfilling, undo, and unlocking the next streak league.

The production archive is for Apple Silicon Macs. The app is ad-hoc signed and has no Apple Developer ID notarization.
