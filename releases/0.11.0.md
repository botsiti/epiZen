# Epizen 0.11.0

Spike has separate Text and Speak controls, clearer capture states, and redesigned preferences.

## Changes

- Correct Retina display selection for the global prompt and provide a fallback when the workspace
  window is hidden. A delayed close from an earlier opening cannot hide a newer prompt.
- Replace the desktop companion's close button with Text; Speak starts dictation. Hide Spike from
  its settings. The prompt opens near the display edge, with a short entrance and companion hop.
- Show microphone energy while listening, with explicit send, cancel, transcription and retry states.
- Choose the assistant model and reasoning effort from dropdowns. Custom model identifiers remain
  available; the selected effort is sent to both Codex and the OpenAI API adapter.
- Optional Liquid glass adds native macOS material to the prompt and softer grouped settings surfaces.
  Ambient movement is optional; Reduce Motion is respected. Appearance can be saved while offline.
- Replace the assistant header's text-symbol controls with consistent line icons.

## Compatibility and validation

Notes remain ordinary Markdown; credentials remain in Keychain. Existing settings default to solid
surfaces and low effort. Tests use isolated vault copies, synthetic recordings and fake providers.
The release PR records final regression, visual and on-device speech verification results. Live
provider access still depends on the selected account and model.

For macOS on Apple Silicon. Ad-hoc signed, not Apple Developer ID notarized. Roll back by installing
an earlier GitHub Release; never overwrite notes when rolling back the app.
