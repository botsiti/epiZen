# Epizen 0.13.0

Home now shows how much of your chosen lifetime has passed. Set your birth date and expected years to live in Settings → Homepage. The default is 80 years. Home and Summaries use the same percentage, alongside the year and month.

Library and Quests each have a settings page with a per-vault enable switch. Library holds catalogue sources and podcast artwork. Homepage settings let you hide the recent-library shelf while continuing to use Library.

In Settings → Quests, choose the life spheres you track, map daily task tags to them, and set XP per logged minute. You can split an activity's XP across multiple spheres and set starting rewards for new quest tiers. Completed focus-timer sessions use the same rules as manually logged minutes. Quests and Statistics show the sphere XP earned from tasks.

Renaming a tag or sphere preserves its history. Archiving it keeps earned credit. Settings shows the effective date for rate and split changes. If time is already logged today, those changes start tomorrow. XP settings live outside the vault, and configuring rewards does not rewrite Markdown.

The local fast gate passed with 962 frontend tests and 116 Rust tests, including timer scoring, historical credit, settings recovery and vault file integrity. The release pull request records desktop validation.

For macOS on Apple Silicon. The app is ad-hoc signed. Apple Developer ID notarization is unavailable for this build. To roll back, reinstall Epizen 0.12.0 and keep your vault and settings.
